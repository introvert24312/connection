# UI 界面定制说明

本文档记录了为保持界面简洁而进行的UI定制修改。

## 标题栏清理修改

### 主要目标
移除界面中所有不必要的标题显示，保持界面简洁干净。

### 修改详情

#### 1. 主窗口标题
**位置**: `WordTaggerApp.swift:3251`
```swift
// 修改前
WindowGroup("节点标签管理器") {

// 修改后
WindowGroup("") {
```
**说明**: 将主窗口标题设置为空字符串，避免显示应用名称或"Connection"。

#### 2. 侧边栏导航标题
**位置**: `TagSidebarView.swift:123`
```swift
// 修改前
.navigationTitle("标签")

// 修改后
// 完全删除此行
```
**说明**: 移除侧边栏的"标签"导航标题。

#### 3. 节点列表导航标题
**位置**: `WordListView.swift:189`
```swift
// 修改前

// 修改后
// 完全删除此行

**说明**: 移除节点列表的"节点"导航标题。

#### 4. 设置页面应用名称
**位置**: `SettingsView.swift:2715-2717`

```

## 效果
- ✅ 主窗口标题栏不显示任何文字
- ✅ 侧边栏顶部干净无标题

- ✅ 设置页面不显示应用名称
- ✅ 整体界面更加简洁

## 注意事项
- 这些修改只影响UI显示，不影响任何功能逻辑
- 所有交互、快捷键、业务逻辑保持完全不变
- 如需恢复标题显示，可参考此文档反向操作
