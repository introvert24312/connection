# 更新日志

## [1.1] - 2025年9月18日

### 🔧 关键修复
- **命令解析重构**: 修复了编辑节点时地点坐标解析错误的问题
  - 问题：命令行编辑器使用简单空格分词，导致 `[白鹭洲书院, 吉安市, 江西省]` 被错误分割
  - 解决：使用智能分词函数 `smartTokenize`，正确处理括号内的逗号
  - 影响：新建节点正常，编辑现有节点时出现错误标签如 `吉安市,`
- **地图坐标选择优化**: 地图选择器现在总是返回空的 `[]`，让用户自定义地名
  - 之前：`loc @27.132...[江西吉安一中, 吉安市, 江西省]` (自动填充长地名)
  - 现在：`loc @27.132...[]` (用户自填简洁地名)

### ✨ 用户体验改进
- **更好的地名控制**: 用户可以输入简洁地名如 `[吉安]` 而不是冗长的自动地名
- **一致的解析行为**: 新建和编辑节点现在使用相同的分词逻辑
- **减少错误标签**: 避免了因分词错误产生的无效标签类型
